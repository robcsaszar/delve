# Contributing

Thanks for considering a contribution to `delve`. This repo publishes one skill; the bar for a change is whether it makes the skill a better, more generic research collaborator, not whether it's a good idea in general.

## Making a change

1. Fork and branch from `main`.
2. Keep the skill's core stance intact: confidence-flagging, explicit uncertainty, and source citation. If you're proposing a change to that stance, open an issue first.
3. Check the change doesn't introduce project-specific assumptions. This skill needs to work for any topic, not one domain.

## Questions

Open an issue. There's no separate chat or forum for this project.
